# Ao-chan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ao-chan, Ina's grimoire, sometimes comes for a turn and rests on the summoning circle's lower-left mark beside Ina.

**Architecture:** `Scene` gains `ao: boolean`, rolled in `wake` from the turn id and cleared when a doze settles. `draw` adds Ao-chan's group inside Ina's group, with arrival CSS on `wake`, exit CSS on `doze`, and a static resting style otherwise. Her art, lines and keyframes live in a new `ao.js`, like `frieren.js`.

**Tech Stack:** Plain ES modules producing SVG strings; tests in `register.test.tsx` run with `claude plugin test plugins/anime-themes`.

**Spec:** `docs/superpowers/specs/2026-11-18-ao-chan-design.md`

## Global Constraints

- Roll: `hash('ao:' + id) % 5 === 0`, only when waking from sleep; independent of Frieren's roll.
- Placement: book about 18 × 24 at about (−27, 19) in the head grid; no frame reaches further left or down than the closed book.
- Lines, verbatim: `AO-CHAN!!` (nerd wake, at 0.6 s), `AO-CHAN GET!` (Frieren, at 2.0 s, `dur` 1.8), `BYE BYE,\nAO-CHAN~` (nerd ending on done/stop/oops); pool `READ ALONG,\nAO-CHAN~`, `WHICH PAGE,\nAO-CHAN?`, `NO PEEKING,\nAO-CHAN!`, `AO-CHAN SAYS HI~`, which takes the 20 s line half the time.
- SVG under 131,072 characters with Frieren + Ao-chan + 14 takodachis coming and going.
- No `Math.random` in state changes; tests deterministic.
- Atom shape tag `scene-3` → `scene-4`.
- Resting state is static style; animations only for arrival, flips, blinks and exit; nothing of hers animates in `wait`.

## Review Focus

1. A subagent joining mid-arrival (`join(wake(...))`): Ao-chan stays, drawn at rest with no arrival replay. Test in Task 2.
2. A turn that ends on a question with Ao-chan: the standing `YOUR TURN~` family stays and no `BYE BYE` is said. Test in Task 2.
3. A question mid-turn (`wait`): Ao-chan visible, no animation on her group. Test in Task 2.
4. Reduced motion (`animation:none`): Ao-chan's resting style must leave her visible in `work`. Covered by Task 2's "static style" rule; check by eye in Task 3.
5. Frieren + Ao-chan geometry: the book clears Frieren's twin tail (x ≥ −6) and ear. Check by eye in Task 3.

**Interfaces:**

  - `AO_HI = 'AO-CHAN!!'`, `AO_GET = 'AO-CHAN GET!'`, `AO_BYE = 'BYE BYE,\nAO-CHAN~'`, `AO_SAY` (the four-line pool).
  - `aoChan(scene, wahs): string`: her whole group `<g class="ao">…</g>`, with a child per frame (`closed`, `blink`, `open` in classes `ac`, `ab`, `ao-open`), the mark's glow and motes for arrival, the ink puff for exit, and WAH-timed flips built with `plays` the way `takodachi` builds hops (move `plays` into reach, e.g. pass it in or export it). It returns `''` when `!scene.ao` or `scene.ina === 'sleep'`.
  - `SPARKS: string`: sparkles round Ina's head for her excited hop, drawn only on an Ao-chan `wake`.

```ts
test('the scene draws Ao-chan arriving, resting, and leaving, and Ina greets her', () => {
  const on = wake(ASLEEP, AO)
  expect(draw(on)).toContain('class="ao"')
  expect(draw(on)).toContain('class="ao-in"')
  expect(draw(on)).toContain(speechOf('AO-CHAN!!'))
  expect(draw(wake(ASLEEP, BOTH))).toContain(speechOf('AO-CHAN GET!'))

  expect(joined).not.toContain('class="ao-in"')

})
```
